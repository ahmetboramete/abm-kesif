# ABM Keşif ve Metraj

Kişisel keşif, plan çizimi ve metraj uygulaması (tablet, kurulabilir web uygulaması).

- Adres: https://ahmetboramete.github.io/abm-kesif/
- Kayıtlar cihazda (tarayıcı depolaması) tutulur; bu repoda veri yoktur, sadece program kodu vardır.
- Çıktılar: metraj tablosu (CSV), plan çizimi (DXF, cm).
